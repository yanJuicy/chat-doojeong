## 기존 문서 재색인

새 Qdrant payload(`labels`, `filename`, `pipeline_version`)와 페이지 번호는 새로 처리된 청크부터 채워진다.
두정테크 문서는 기존 OCR 자체가 깨졌으므로 라벨 저장이 아니라 다음 API로 원문 추출부터 다시 시작한다.

```powershell
curl.exe -X POST http://127.0.0.1:8000/api/documents/문서ID/reextract
```

이 API는 사용자가 붙인 라벨과 원본 파일은 보존하고, 잘못된 OCR·청크·Qdrant 벡터만 다시 만든다.

OCR 품질이 기준 미달이면 상태가 `needs_review`가 되며 검색에는 들어가지 않는다. 콘솔의 경고와
`GET /api/documents/{id}/status`에 표시되는 `extraction_quality_details`를 확인한다.

## 두정테크 회귀 평가

`docs/EVAL_QUESTIONS.json` 내용을 그대로 다음 API에 POST한다.

```text
POST http://127.0.0.1:8000/api/evaluation/run
Content-Type: application/json
```

확인 기준:

- `expected_hit=true`
- `expected_rank=1`에 가까울 것
- `expected_terms_hit=true`
- 답변과 출처에 실제 페이지 번호가 표시될 것
