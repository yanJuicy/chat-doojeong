## 이미 알려진 한계 (새로 발견한 게 아니라 참고용)

- Query Expansion: "회사→기업" 확장이 검색어에는 반영되나 검색 결과에는 반영 안 됨 (원인 미규명)
- 위키백과 재크롤링으로 생긴 제목은 같고 document_id는 다른 유사 문서들 — `dedupe-documents`(완전 일치 기준)로는 안 잡힘, 참고자료 화면에서는 제목 기준 필터링으로 우회 처리함
- "로봇공학자" 카테고리 질문이 더 풍부한 "로봇공학" 본문에 밀리는 경향 (Parent-Child로도 해결 안 된 사례)
