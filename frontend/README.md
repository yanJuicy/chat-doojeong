# RAG React Frontend

FastAPI 기반 사내 문서 RAG에 연결하는 React 프론트엔드입니다.

## 구현된 기능

- `/api/chat` 질문 및 답변 표시
- `/api/chat/stream` 기반 단계별 진행상황과 답변 스트리밍
- 답변 출처와 원본 문서 열기
- 답변에 포함된 참고 이미지 표시
- `/api/documents` 문서 목록과 상태 표시
- 여러 문서 업로드
- 업로드 완료 후 OCR→청킹→임베딩 자동 시작
- 자동 시작 실패 시 사용할 수 있는 수동 `처리 시작` 버튼
- 파일별 라벨 및 공통 라벨 적용
- 공통·파일별 라벨 입력 자동완성(문자를 입력했을 때만 표시)
- ZIP 업로드
- 처리 중 문서 5초 간격 자동 갱신
- 파일명·라벨 검색과 상태 필터
- 문서 선택 및 최대 100개 일괄 삭제
- 문서 상세 정보·청크·추출 품질 확인
- OCR 페이지 단위 상세 처리 진행률
- 실패 원인 확인과 재시도·OCR 재추출
- 문서 라벨 수정 후 자동 재색인
- `/health` 기반 서버 정상·점검 필요·연결 안 됨 표시
- 답변 생성 중지와 새 메시지 자동 스크롤
- 대화 제목 지정·수정
- 이전 대화 목록·선택·삭제
- 브라우저 새로고침 후 대화 및 출처 복원
- 선택한 AI 답변에 실제 사용된 출처만 표시
- 출처와 상세 청크에서 정확한 PDF 페이지 열기
- 모바일 답변 출처 팝업
- 모바일 대화 내역 슬라이드 메뉴
- 모바일 반응형 화면

## 개발 실행

FastAPI를 먼저 `127.0.0.1:8000`에서 실행한 뒤:

```powershell
pnpm install
pnpm dev
```

브라우저에서 `http://localhost:5173`으로 접속합니다.

같은 와이파이의 다른 기기에서는 터미널에 표시된 Network 주소 또는
`http://발표용PC의-내부-IP:5173`으로 접속합니다. Vite가 `/api`, `/health`,
`/images` 요청을 발표용 PC의 FastAPI로 전달합니다.

## 빌드

```powershell
pnpm build
```

결과는 `dist/` 폴더에 만들어집니다.

## API 주소 변경

기본값은 상대 경로이며 개발 중에는 Vite 프록시를 사용합니다. 별도 API 주소가
필요하면 `.env` 파일을 만들고 다음처럼 지정합니다.

```env
VITE_API_BASE=http://192.168.0.15:8000
```

이 방식으로 다른 기기의 브라우저가 FastAPI에 직접 접속하면 FastAPI의
`0.0.0.0` 바인딩, Windows 방화벽 및 CORS 설정도 필요합니다. 같은 PC의 Vite
프록시를 사용하는 기본 구성이 시연에는 더 간단합니다.

## 소스 구조

```text
src/
├─ App.jsx                 # 최상위 화면 조립만 담당
├─ api.js                  # FastAPI/SSE 통신
├─ components/
│  ├─ chat/                # 채팅 메시지·입력·워크스페이스
│  ├─ documents/           # 업로드·라벨·문서 목록·서랍
│  ├─ sources/             # 선택한 답변의 출처 카드·PC/모바일 출처 화면
│  ├─ conversations/       # 대화 제목·목록·선택·삭제 UI
│  └─ layout/              # 좌측 메뉴·상단바
├─ hooks/                  # 채팅·문서·서버 상태 등 상태/동작
├─ constants/              # 문서 상태 등 공통 고정값
└─ utils/                  # 포맷·라벨·서버 표시 변환 함수
```

새 기능은 `App.jsx`에 직접 구현하지 않고 해당 기능 폴더의 컴포넌트와 훅에 추가한다.
구체적인 유지 규칙은 `frontend/AGENTS.md`를 따른다.
